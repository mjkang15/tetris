# 테트리스 프로젝트 개발 계획

## 개요

브라우저에서 파일을 바로 열어 실행할 수 있는 테트리스 게임.
별도 서버나 빌드 없이 `landing.html`(소개) → `index.html`(게임) 순으로 이동.

---

## 파일 구조

```
tetris/
├── landing.html   # 랜딩 페이지 (소개 · 사용법 · 게임 링크)
├── landing.css    # 랜딩 페이지 스타일
├── landing.js     # 히어로 미니 애니메이션 캔버스
├── index.html     # 게임 페이지 마크업
├── style.css      # 게임 페이지 스타일
├── game.js        # 게임 전체 로직
└── plan.md        # 이 파일
```

## 랜딩 페이지 (landing.html / landing.css / landing.js)

### 레이아웃

| 섹션 | 내용 |
|------|------|
| Hero | TETRIS 타이틀 + 소개 문구 + 미니 애니메이션 캔버스 + 플레이 버튼 |
| 게임 특징 | 카드 4장 — 테트로미노 · 레벨/속도 · 미리보기 · BGM |
| 조작 방법 | 키보드 4가지 조작 안내 |
| 점수 계산 | 클리어 줄 수별 점수 표 |
| CTA | 게임 시작 버튼 |
| Footer | 저작권 |

### 주요 동작
- Hero 우측 캔버스(150×300 px)에서 블록이 실제로 떨어지는 미니 게임 자동 실행
- "지금 플레이하기" / "게임 시작하기" 버튼 → `index.html` 이동
- 반응형 (640px 이하에서 히어로 섹션 세로 배치)

## 게임 페이지 (index.html / style.css)

### 레이아웃

```
← 소개 페이지
     TETRIS
┌──────────────┬─────────────┐
│              │  [NEXT 미리보기]│
│  게임보드     │  SCORE      │
│  10×20       │  LEVEL      │
│  (Canvas)    │  LINES      │
│              │  [조작키 안내]│
└──────────────┴─────────────┘
```

- `<canvas id="board">` — 메인 게임 보드 (300×600 px, 10×20 셀)
- `<canvas id="next">` — 다음 블록 미리보기 (100×100 px, 4×4 셀)
- 좌상단 "← 소개 페이지" 링크 → `landing.html`
- 게임 오버 시 전면 오버레이 표시

## 게임 로직 (game.js)

### 테트로미노 (7종)

| 종류 | 색상 |
|------|------|
| I | `#00f0f0` (시안) |
| O | `#f0f000` (노랑) |
| T | `#a000f0` (보라) |
| S | `#00f000` (초록) |
| Z | `#f00000` (빨강) |
| J | `#0000f0` (파랑) |
| L | `#f0a000` (주황) |

### 게임 상태

| 변수 | 설명 |
|------|------|
| `board[20][10]` | 쌓인 블록 색상 저장 (`null` = 빈칸) |
| `current` | 현재 낙하 중인 블록 (shape, x, y, color) |
| `nextPiece` | 다음 블록 (미리보기 캔버스에 표시) |
| `score` | 현재 점수 |
| `level` | 현재 레벨 |
| `lines` | 제거한 총 라인 수 |
| `flashingRows` | 클리어 애니메이션 중인 줄 인덱스 배열 |
| `gameStartTs` | 게임 시작 타임스탬프 (시간 기반 레벨 업용) |

### 핵심 함수

| 함수 | 역할 |
|------|------|
| `spawnPiece()` | `nextPiece`를 `current`로 승격, 새 `nextPiece` 생성 |
| `movePiece(dx, dy)` | 이동 + 충돌 감지, 바닥 충돌 시 `lockPiece()` 호출 |
| `rotatePiece()` | 시계방향 회전 (벽 킥 ±1칸 지원) |
| `hardDrop()` | Space — 즉시 바닥까지 낙하 |
| `lockPiece()` | 블록을 board에 고정 → 완성 줄 검사 → 플래시 또는 즉시 스폰 |
| `finishLineClear()` | 플래시 종료 후 줄 제거 · 점수 계산 · 다음 블록 스폰 |
| `draw()` | Canvas 전체 렌더링 (고스트 블록 · 플래시 효과 포함) |
| `drawNext()` | 다음 블록 미리보기 캔버스 렌더링 |
| `gameLoop(ts)` | `requestAnimationFrame` 기반 루프 |
| `scheduleBGM(startTime)` | Web Audio API로 멜로디 예약 + 루프 |

### 점수 계산

| 클리어 줄 수 | 기본 점수 |
|------------|---------|
| 1줄 | 100 × 레벨 |
| 2줄 | 300 × 레벨 |
| 3줄 | 500 × 레벨 |
| 4줄 (테트리스) | 800 × 레벨 |

### 레벨 / 낙하 속도

- **시간 기반**: 30초마다 자동 레벨 +1
- **라인 기반**: 10줄 클리어마다 레벨 +1
- 두 조건 중 높은 값 적용
- 낙하 간격: `max(100, 1000 - (레벨-1) × 100)` ms

### 라인 클리어 애니메이션

- 완성 줄을 즉시 제거하지 않고 500ms 동안 흰색/원색 80ms 간격 깜빡임
- 플래시 중 블록 이동 입력 무시
- `finishLineClear()`에서 `Array.filter`로 줄 제거 후 위에 빈 줄 추가

### 배경음악 (BGM)

- Web Audio API `OscillatorNode` (square wave) 사용
- 테트리스 Type-A 코로베이니키 멜로디 (BPM 145)
- Section A + Section B 반복 루프
- 첫 키 입력 또는 재시작 버튼 클릭 시 시작 (브라우저 자동재생 정책 대응)
- 게임 오버 시 중지

### 키보드 조작

| 키 | 동작 |
|----|------|
| `←` / `→` | 좌우 이동 |
| `↓` | 소프트 드롭 |
| `↑` / `Z` | 회전 |
| `Space` | 하드 드롭 |

### 게임 오버 / 재시작

- 새 블록 생성 시 충돌 → 게임 오버 오버레이 + 최종 점수 표시
- "다시 시작" 버튼 → 전체 상태 초기화 + BGM 재시작

## 검증 방법

1. `landing.html`을 브라우저에서 열기 → 히어로 애니메이션 확인
2. "지금 플레이하기" 클릭 → `index.html`로 이동 확인
3. 블록 낙하·이동·회전·하드 드롭 정상 동작 확인
4. 다음 블록 미리보기 표시 확인
5. 라인 클리어 시 깜빡임 애니메이션 후 줄 제거 확인
6. 점수/레벨/라인 수 증가 확인
7. 30초 경과 시 자동 레벨 업 + 낙하 속도 증가 확인
8. 첫 키 입력 후 BGM 재생 확인
9. 게임 오버 → 재시작 → BGM 재시작 확인
10. "← 소개 페이지" 클릭 → `landing.html`로 복귀 확인
