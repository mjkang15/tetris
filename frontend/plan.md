# 테트리스 프로젝트 개발 계획

## 개요

브라우저에서 파일을 바로 열어 실행할 수 있는 테트리스 게임 및 점수 관리 시스템.
별도 서버나 빌드 없이 `index.html`(소개) → `game.html`(게임) 순으로 이동하며, FastAPI 백엔드 서버와 연동하여 사용자 인증 및 최고 점수 실시간 등록/조회 기능을 제공함.

---

## 파일 구조

```text
tetris/
├── backend/                  # FastAPI 백엔드 (Python)
│   ├── main.py               # API 엔드포인트 정의 및 CORS 설정
│   ├── auth.py               # JWT 기반 인증 및 패스워드 검증
│   ├── database.py           # SQLite 커넥션 설정
│   ├── models.py             # SQLAlchemy DB 모델 (User, Score)
│   ├── schemas.py            # Pydantic 데이터 검증 스키마
│   ├── requirements.txt      # 백엔드 의존성 패키지 목록
│   ├── Dockerfile            # 배포용 도커 파일
│   └── tetris.db             # SQLite 로컬 데이터베이스
├── frontend/                 # 프론트엔드 (HTML / CSS / JS)
│   ├── index.html            # 소개 페이지 (소개 · 사용법 · 게임 링크)
│   ├── landing.css           # 소개 페이지 스타일
│   ├── landing.js            # 히어로 미니 애니메이션 캔버스 데모
│   ├── game.html             # 게임 페이지 마크업
│   ├── style.css             # 게임 페이지 스타일
│   ├── game.js               # 게임 전체 로직 & API 연동
│   ├── github_pages.md       # GitHub Pages 배포 가이드
│   └── plan.md               # 이 파일 (개발 계획서)
└── render.yaml               # Render.com 클라우드 서비스 배포 설정
```

## 게임 페이지 (game.html / style.css)

### 레이아웃

```text
← 소개 페이지           [로그인 / 회원가입 또는 사용자명(로그아웃)]
     TETRIS
┌──────────────┬─────────────┐
│              │  [NEXT 미리보기]│
│  게임보드     │  SCORE      │
│  10×20       │  LEVEL      │
│  (Canvas)    │  LINES      │
│              │  [TOP SCORE]│
│              │  [조작키 안내]│
└──────────────┴─────────────┘
```

- `<canvas id="board">` — 메인 게임 보드 (300×600 px, 10×20 셀)
- `<canvas id="next">` — 다음 블록 미리보기 (100×100 px, 4×4 셀)
- 좌상단 "← 소개 페이지" 링크 → `index.html`
- 우상단 유저 정보 영역 및 로그인/로그아웃 버튼 제공
- 게임 오버 시 최종 점수와 백엔드 등록 여부가 전면 오버레이에 표시됨

## 게임 로직 (game.js)

### 테트로미노 (7종)

| 종류 | 색상 |
|------|------|
| I | `#00f0f0` (시안) |
| O | `#f0f000` (노랑) |
| T | `#a000f0` (보라) |
| S | `#00f000` (초록) |
| Z | `#f00000` (빨강) |
| J | `#0000f0` (파랑) |
| L | `#f0a000` (주황) |

### 게임 상태

| 변수 | 설명 |
|------|------|
| `board[20][10]` | 쌓인 블록 색상 저장 (`null` = 빈칸) |
| `current` | 현재 낙하 중인 블록 (shape, x, y, color) |
| `nextPiece` | 다음 블록 (미리보기 캔버스에 표시) |
| `score` | 현재 점수 |
| `level` | 현재 레벨 |
| `lines` | 제거한 총 라인 수 |
| `flashingRows` | 클리어 애니메이션 중인 줄 인덱스 배열 |
| `gameStartTs` | 게임 시작 타임스탬프 (시간 기반 레벨 업용) |

### 핵심 함수

| 함수 | 역할 |
|------|------|
| `spawnPiece()` | `nextPiece`를 `current`로 승격, 새 `nextPiece` 생성 |
| `movePiece(dx, dy)` | 이동 + 충돌 감지, 바닥 충돌 시 `lockPiece()` 호출 |
| `rotatePiece()` | 시계방향 회전 (벽 킥 ±1칸 지원) |
| `hardDrop()` | Space — 즉시 바닥까지 낙하 |
| `lockPiece()` | 블록을 board에 고정 → 완성 줄 검사 → 플래시 또는 즉시 스폰 |
| `finishLineClear()` | 플래시 종료 후 줄 제거 · 점수 계산 · 다음 블록 스폰 |
| `draw()` | Canvas 전체 렌더링 (고스트 블록 · 플래시 효과 포함) |
| `drawNext()` | 다음 블록 미리보기 캔버스 렌더링 |
| `gameLoop(ts)` | `requestAnimationFrame` 기반 루프 |
| `scheduleBGM(startTime)` | Web Audio API로 멜로디 예약 + 루프 |

### 점수 계산

| 클리어 줄 수 | 기본 점수 |
|------------|---------|
| 1줄 | 100 × 레벨 |
| 2줄 | 300 × 레벨 |
| 3줄 | 500 × 레벨 |
| 4줄 (테트리스) | 800 × 레벨 |

### 레벨 / 낙하 속도

- **시간 기반**: 30초마다 자동 레벨 +1
- **라인 기반**: 10줄 클리어마다 레벨 +1
- 두 조건 중 높은 값 적용
- 낙하 간격: `max(100, 1000 - (레벨-1) × 100)` ms

### 라인 클리어 애니메이션

- 완성 줄을 즉시 제거하지 않고 500ms 동안 흰색/원색 80ms 간격 깜빡임
- 플래시 중 블록 이동 입력 무시
- `finishLineClear()`에서 `Array.filter`로 줄 제거 후 위에 빈 줄 추가

### 배경음악 (BGM)

- Web Audio API `OscillatorNode` (square wave) 사용
- 테트리스 Type-A 코로베이니키 멜로디 (BPM 145)
- Section A + Section B 반복 루프
- 첫 키 입력 또는 재시작 버튼 클릭 시 시작 (브라우저 자동재생 정책 대응)
- 게임 오버 시 중지

### 키보드 조작

| 키 | 동작 |
|----|------|
| `←` / `→` | 좌우 이동 |
| `↓` | 소프트 드롭 |
| `↑` / `Z` | 회전 |
| `Space` | 하드 드롭 |

### 모바일 조작 (터치)

**캔버스 제스처:**

| 제스처 | 동작 |
|--------|------|
| 탭 | 회전 |
| 좌우 드래그 | 블록 이동 (20px마다 1칸) |
| 위로 스와이프 | 회전 |
| 아래로 스와이프 | 하드 드롭 |

**화면 하단 버튼 패널 (터치 기기에서만 표시):**

| 버튼 | 동작 |
|------|------|
| `◀` | 왼쪽 이동 (꾹 누르면 자동 반복) |
| `↻` | 회전 |
| `▶` | 오른쪽 이동 (꾹 누르면 자동 반복) |
| `▼` | 소프트 드롭 (꾹 누르면 자동 반복) |
| `⬇` | 하드 드롭 |

### 모바일 레이아웃

- 게임 영역(`game-area`)을 CSS `transform: scale()`로 화면 너비에 맞게 자동 축소
- 리사이즈 시 `scaleGameArea()`가 재계산 (`window.resize` 이벤트)
- 하단 버튼 패널은 `position: fixed; bottom: 0`으로 항상 화면 아래 고정
- iOS 홈 인디케이터 영역은 `env(safe-area-inset-bottom)`으로 자동 처리
- `user-scalable=no`로 게임 중 핀치 줌 방지
- 터치 기기에서 키보드 조작 안내 패널 자동 숨김

### 게임 오버 / 재시작

- 새 블록 생성 시 충돌 → 게임 오버 오버레이 + 최종 점수 표시
- "다시 시작" 버튼 → 전체 상태 초기화 + BGM 재시작

## 백엔드 API 및 인증 (FastAPI)

### 인증 구조
- JWT (JSON Web Token) 기반 Access Token 인증을 사용합니다.
- 로그인/회원가입 후 발급받은 Access Token은 브라우저의 `localStorage` (`tetris_token` 키)에 보관하며, API 호출 시 `Authorization: Bearer <token>` 헤더로 전달합니다.
- 현재 로그인 정보는 `localStorage` (`tetris_user` 키)에 JSON 구조로 동기화됩니다.

### 데이터베이스 스키마
- **users**: 사용자 테이블 (`id`, `email`, `username`, `hashed_password`, `created_at`)
- **scores**: 점수 테이블 (`id`, `user_id`, `score`, `lines`, `level`, `played_at`) - User 테이블과 1:N 관계를 맺습니다.

### API 명세

| 엔드포인트 | 메서드 | 인증 필요 | 설명 |
|---|---|---|---|
| `/auth/register` | POST | X | 이메일, 닉네임, 패스워드로 신규 사용자 가입 및 JWT 토큰 반환 |
| `/auth/login` | POST | X | 이메일과 패스워드로 로그인 처리 및 JWT 토큰 반환 |
| `/auth/me` | GET | O | 현재 인증된 사용자 정보 가져오기 |
| `/scores` | POST | O | 게임 오버 시 획득한 점수, 라인 수, 최종 레벨 저장 |
| `/scores/top` | GET | X | 전체 유저 중 최고 기록(점수, 유저명, 기록 일시) 조회 |
| `/scores/me` | GET | O | 최근 본인이 기록한 점수 상위 10개 내역 조회 |

## 검증 방법

1. `index.html`을 브라우저에서 열기 → 히어로 애니메이션 확인
2. "지금 플레이하기" 클릭 → `game.html`로 이동 확인
3. 블록 낙하·이동·회전·하드 드롭 정상 동작 확인
4. 다음 블록 미리보기 표시 확인
5. 라인 클리어 시 깜빡임 애니메이션 후 줄 제거 확인
6. 점수/레벨/라인 수 증가 확인
7. 30초 경과 시 자동 레벨 업 + 낙하 속도 증가 확인
8. 첫 키 입력 후 BGM 재생 확인
9. 게임 오버 → 재시작 → BGM 재시작 확인
10. "← 소개 페이지" 클릭 → `index.html`로 복귀 확인
11. 모바일에서 하단 버튼 패널 표시 확인
12. 캔버스 탭·드래그·스와이프 제스처 동작 확인
13. 좁은 화면에서 게임 영역 자동 축소 확인
14. 우상단 "로그인 / 회원가입" 버튼 클릭 후 모달 작동 여부 확인
15. 회원가입 및 로그인 정상 처리 후 세션 유지 및 닉네임 표시 확인
16. 로그인 상태에서 게임 오버 시 백엔드 데이터베이스로의 점수 전송 및 탑 스코어 실시간 갱신 확인
17. 로그아웃 클릭 시 로컬 세션 삭제 및 비인증 상태 전환 확인
